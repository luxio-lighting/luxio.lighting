Getting Started

Three easy steps to make your own Wi-Fi LED strip.

  1. Shop for hardware

    Buy an ESP32-based LED controller, a power supply and a LED strip.

    • ESP32
    • ESP32-S3
    • ESP32-S31
    • ESP32-C3
    • ESP32-C5
    • ESP32-C6

  2. Connect the LEDs

    Connect your strip and power supply following your controller’s instructions.

    • WS2811
    • WS2812
    • WS2812B
    • WS2813
    • WS2815
    • WS2814
    • SK6812
    • WS2805

  3. Flash & Connect

    Open the Luxio Web App, add a new device by tapping and flash via USB.

Lua-nimations

Apply one of the presets, or code your own animation. Try Luxio Studio on the web in a simulator or a real device.

-- A rainbow that moves along your strip.
function loop()
  local count = luxio_get_pixel_count()
  local time = luxio_millis() / 20000

  luxio_fill_hsv(time, 1 / count)
end

Script with Luxio CLI

Control Luxio from scripts and cronjobs. Discover lights, set colors and play animations from your terminal.

Terminal
$ npm install -g @luxio-lighting/cli
$ luxio --device "Living Room" on
$ luxio --device "Living Room" brightness 192
$ luxio --device "Living Room" set-gradient ff0000,00ff00,0000ff
